# Repository contribution rules

- Use `lyraEz` as the author and committer when the environment supports it.
- Keep commit and pull-request text concise, natural, and focused on the change.
- Do not add automated-tool attribution, co-author trailers, generated-by notices, signatures, watermarks, promotional text, or session links.
- Do not add tool references to source code, comments, or documentation unless they are technically required by the project.
- Preserve `.readmee/settings.json` and its disabled attribution settings.
